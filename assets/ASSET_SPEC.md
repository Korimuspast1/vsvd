# Asset Specification

Original low-poly assets should use desaturated Source-era styling, 128-512px textures, hard specular response, and simple collision meshes. Do not import copyrighted models, textures, or audio from other games.

Priority assets: observatory modular kit, CRT terminal, coordinate panel, detector, tape drives, breaker panel, dishes, bed, kitchen props, forest kit, visitor entity, stag-shadow entity, vent crawler, gravity tool.
