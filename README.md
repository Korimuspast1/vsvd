# VSVd — Void Signal Vigil

Godot 4.3+ foundation for an original first-person atmospheric signal-observatory survival simulation: player controller, interaction system, signal acquisition/processing, terminal UI, save/load, day cycle, needs, anomalies, email, upgrades, achievements, data-driven resources, and a playable MIT-attributed procedural valley map.

This repository intentionally includes no proprietary assets, ripped code/audio/models/textures, or exact copyrighted story content from any existing game. It is a legally-distinct scaffold with placeholder content and original naming. Replace placeholders with properly licensed or original assets before distribution.

## Run
Open this folder in Godot 4.3+ and run `res://scenes/main/Main.tscn`.

## Validate without Godot

```bash
python3 tools/validate_project.py
```

## Controls
WASD move, mouse look, Shift sprint, Ctrl crouch, Space jump, E interact, Tab inventory, Esc pause.
